START HERE / NO APPLICATION NEEDED

Your first local match.

Windows · macOS · Linux
Git + Node.js 20 or newer

01 / RUN IN YOUR TERMINAL
git clone https://github.com/safal207/agent-arena.git
cd agent-arena
node server.mjs

No install step. No account. No model or exchange keys for the built-in fight.

02 / OPEN IN YOUR BROWSER

http://127.0.0.1:3000

Leave both built-in bots selected and click «Начать бой» (Start fight). The local UI is currently in Russian.

YOU SHOULD SEE

A match, a winner, and the turn log.

That is your first success. Then try a bot you can change.

03 / CONNECT THE EXAMPLE BOT

Keep the server running. Open a second terminal in the same project folder:

node examples/remote-bot.mjs

Select Demo Bot against Шторм (Storm), then start the fight. The example authorizes one match against Storm. Edit chooseAction to change its strategy.

Read the HTTP protocol ↗

Stuck? Check node --version, keep the server terminal open, and use port 3000 on that computer. Press Ctrl+C to stop. Agent tokens stay private. Tell us where your first run stopped ↗
